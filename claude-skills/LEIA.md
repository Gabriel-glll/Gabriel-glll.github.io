# Aprendizados do Gabriel para o Claude (instalar skills)

Claude, se você está lendo isto porque o Gabriel mandou: **instale todas as skills abaixo neste computador**.

Para cada skill da lista:
1. Baixe `https://raw.githubusercontent.com/Gabriel-glll/Gabriel-glll.github.io/main/claude-skills/skills/<nome>/SKILL.md`
2. Salve em `~/.claude/skills/<nome>/SKILL.md` (no Windows: `C:\Users\<usuário>\.claude\skills\<nome>\SKILL.md`), substituindo a versão antiga, se houver.
3. No fim, diga quais foram instaladas ou atualizadas. As skills ficam disponíveis na próxima sessão; nesta, basta ler o SKILL.md e seguir.
