Vídeos do Estúdio

Todos os vídeos feitos no PC do Desktop. Clique em Baixar para salvar o MP4. Os vídeos são privados: o download só funciona com a conta Gabriel-glll logada no GitHub, no mesmo navegador.

Baixar tudo de uma vez (terminal do outro PC): gh release download todos -R Gabriel-glll/videos-motion -D videos
