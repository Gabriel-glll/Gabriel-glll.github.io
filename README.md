# Gabriel Gil — Corretor de Imóveis

Landing page pessoal de **Gabriel Gil Rodrigues**, corretor de imóveis em **Campinas e região**.

🔗 **Site:** https://gabriel-glll.github.io/

## O que tem no site
- **Sobre mim** — apresentação, valores e diferenciais
- **Por que comprar comigo** — transparência, honestidade, burocracia resolvida e acompanhamento
- **Destaques** — empreendimentos com galeria de fotos, comodidades e contato direto no WhatsApp
- **Mercado imobiliário** de Campinas e informações sobre **construtoras**
- **Contato** — WhatsApp, e-mail e Instagram

## Como editar
Site estático de arquivo único:
- `index.html` — toda a página (estrutura, estilos, textos e dados dos empreendimentos no bloco `PROPS` do `<script>`)
- `assets/` — fotos dos empreendimentos e foto de perfil
- As fontes (Fraunces + Manrope) estão embutidas no próprio HTML

Para trocar textos ou empreendimentos, edite o `index.html`. Ao dar `git push` na branch `main`, o GitHub Pages publica automaticamente.
